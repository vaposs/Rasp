Что такое "Венгерская нотация"?
Это система именования переменных, при которой к имени добавляется префикс, указывающий на тип данных:
string strName;      // str = string
int iCount;          // i = integer
bool bIsActive;      // b = boolean
float fPrice;        // f = float
DateTime dtCreated;  // dt = DateTime
TextBox txtUserName; // txt = TextBox
